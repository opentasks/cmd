# Task 21 Verification Report

## Task: "New items created in wrong location" (Bug Fix)

### Problem Statement
When creating new tasks via CLI, they were not being saved in the correct project location due to:
1. Incorrect TOML config format generated by `config init`
2. Config discovery not properly handling hierarchical project structures

### Fixes Implemented

#### 1. Config Init Command (cmd/config.go:251-296)
**Problem:** Generated config with nested sections `[project.storage]` instead of flat schema
```toml
# WRONG (before)
[project.project]
name = "test"

[project.storage]
path = "./.tasks"
```

**Solution:** Changed to correct flat schema format
```toml
# CORRECT (after)
[project]
name = "test"

[storage]
path = "./.tasks"
```

#### 2. Config Discovery (internal/config/discovery.go:31-58)
**Problem:** Discovery continued walking up past git repository roots
**Solution:** Added git root detection - discovery now stops when `.git` directory is found
