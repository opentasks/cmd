# Query Engine and Filtering

## Design Decision

Query engine provides a thin wrapper around storage's ListTasks with convenience methods and functional option filters. Advanced features deferred to roadmap.

## Functional Options Pattern

Storage uses functional options for composable filtering:

```go
type TaskFilter func(*Task) bool

tasks, err := storage.ListTasks(
    WithStatus("in-progress"),
    WithType("story"),
    WithTag("feature"),
    WithParent(5),  // Parent epic ID (numeric)
)
```

## Filter Helpers

Built-in filter constructors:

```go
func WithStatus(status string) TaskFilter
func WithType(taskType string) TaskFilter
func WithTag(tag string) TaskFilter
func WithParent(parentID int) TaskFilter         // Takes int ID
func WithRelationship(relType string, taskID int) TaskFilter
func WithTags(tags []string) TaskFilter  // Match any tag
func WithStatuses(statuses []string) TaskFilter  // Match any status
```

## Query Engine Methods

```go
type QueryEngine struct {
    storage BaseStorage
}

func (q *QueryEngine) FindByID(id int) (*Task, error)
func (q *QueryEngine) FindChildren(parentID int) ([]*Task, error)
func (q *QueryEngine) FindBlocking(taskID int) ([]*Task, error)
func (q *QueryEngine) FindBlockedBy(taskID int) ([]*Task, error)
func (q *QueryEngine) FindRelated(taskID int) ([]*Task, error)
```

## Composition Example

```go
engine := NewQueryEngine(storage)

// Get all in-progress stories for epic 5
stories, err := engine.ListTasks(
    WithStatus("in-progress"),
    WithType("story"),
    WithParent(5),  // Epic ID
)

// Get all tasks blocked by task 42
blocked, err := engine.FindBlocking(42)
```

## Future Enhancements (Roadmap)

- Full-text search across task descriptions
- Dependency graph analysis
- Critical path calculation
- Advanced relationship traversal
- Query language (DSL) for complex filtering

## Implementation Notes

- QueryEngine wraps storage, doesn't replace it
- Filters composed at call site (no query builder needed)
- All filtering happens in-memory (acceptable for typical project sizes)
- Storage layer remains simple and focused
